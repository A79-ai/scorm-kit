# Privacy policy

SCORM Kit is a skill: a Python script plus instructions. The script runs on
your machine, or in the sandbox of the assistant you use, and works only on the
course files you give it.

- **What it collects:** nothing. The script makes no network requests. It
  sends no telemetry, analytics or crash reports, and it stores no user data.
  The test suite checks this.
- **Where your data goes:** only where you put it. The script writes its output
  to the folder you choose. Your assistant (Claude, ChatGPT, Codex) handles the
  conversation and any files under its provider's own privacy policy.
- **Retention:** the script keeps nothing. Delete the output folder to remove
  everything it made.
- **Third parties:** none. The viewer page loads no remote scripts, fonts or
  images.

Questions: open an issue at https://github.com/A79-ai/scorm-kit/issues.
